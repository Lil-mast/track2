# Frontend (Next.js)

This repo uses **Next.js (App Router)** with **TypeScript** and **Tailwind CSS**.

## Prerequisites
- Node.js 18+ recommended
- Package manager: npm

## Install
```bash
npm install
```

## Run (dev)
```bash
npm run dev
```
Then open:
- http://localhost:3000

## Build (production)
```bash
npm run build
npm run start
```

## Lint / Typecheck
```bash
npm run lint
npx tsc --noEmit
