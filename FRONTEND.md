# Frontend (Next.js)

This repo uses **Next.js (App Router)** with **TypeScript** and **Tailwind CSS**.

## Prerequisites
- Node.js 18+ recommended
- Package manager: pnpm

## Install
```bash
pnpm install
```

## Run (dev)
```bash
pnpm run dev
```
Then open:
- http://localhost:3000

## Build (production)
```bash
pnpm run build
pnpm run start
```

## Lint / Typecheck
```bash
pnpm run lint
pnpm exec tsc --noEmit
